# Meherwer Ali

**Senior Software Engineer · Backend Platforms · Distributed Systems**

I design and build reliable backend systems, event-driven services, and developer tooling using Java, Spring, Kafka, Python, and TypeScript.

My public work focuses on making architecture, failure handling, observability, testing, and operational trade-offs explicit—not just demonstrating happy-path code.

## How I Approach Engineering

I prefer systems where:

- failure behavior is designed rather than left implicit;
- retries and duplicate delivery are treated as normal conditions;
- operational claims are backed by tests, metrics, or reproducible commands;
- examples are small enough to understand but realistic enough to be useful;
- public portfolio work remains separate from employer and client source code.
